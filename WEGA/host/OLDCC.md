# The old C compilers of WEGA

What is known now about the C compiler revisions that built the WEGA binaries: the versions we rebuild, how they differ
from the shipped compiler, and which object shows which difference. This file holds current facts only. How they were
found, attempts, refuted ideas and removed switches are in `OLDCC_LOG.md`; which function needs which switch is in
`OLDCC_SWITCHES.md` (generated); the evidence per function is in the findings.json of each program
(`compare/*/findings.json`). The rules for this work are in `HOWTO_reconstruct.md`, "Evidence rules".

## State

With `make PROG CC=ccv0p` and strip these are byte-identical with the originals: cpp, cparse, scparse, codgen, scodgen,
popt, spopt. With v1: size, strip, mv (also cp, ln), rm. With v1r: write, rmdir. With v0: dc, ranlib. v1q builds libc modules of its time. v1 and v0 are not complete (section 5).

## 1 Terms and building

- **shipped**: the compiler of the WEGA 3.1 tree (`/bin/cc`, `/bin/scc` and their passes `/lib/cparse`, `/lib/codgen`,
  `/lib/popt`, `/lib/scparse`, `/lib/scodgen`, `/lib/spopt`). Our normal build uses it.
- **old**: a revision of the compiler that built an original binary and of which no binary exists. Its output is only
  known from the binaries it made.
- **Dn**: one difference between the output of an old compiler and that of the shipped one (section 3).
- **switch** `OLD_Dn`: a compile-time switch in the sources of a pass that turns the shipped behaviour into the old one.
  The normal build sets none, so it stays byte-identical with the shipped passes.
- **version** vN: a set of switches that together give one old compiler (section 2), built in `src/cmd/<pass>/vN` and
  run through the driver `ccvN`.
- **witness**: a function whose original code a switch makes equal. **Test bench**: `host/recon/witness.py`, the
  System III sources of WEGA programs of one compiler time, compiled with a version and aligned with the originals. WEGA
  changed many of these sources, so a difference on the bench is not a compiler difference by itself.

`cc` runs cpp > cparse > [gopt] > codgen > popt > cas > ld (`scc`: scparse, scodgen, spopt, sld). cparse writes the
intermediate tree (`.I`) and the data as cas text (`.D`); codgen chooses registers, frame and instructions; popt is the
peephole optimizer (descends from the Plexus `c2`); cas decides the jump forms.

- The old versions are native WEGA programs only (built with the shipped cc, run in the emulator). The host versions
  (`host/codgen`, `host/popt`, ...) get no switches, except `host/cas/casold`, used by the models.
- One source and one Makefile per pass; every old version is a target of it, built in its own directory with its switches
  (`src/cmd/cparse/build/nonsegv1`, `codgen/build/nonsegv1q`, ..., the segmented v1 passes in `build/segv1`; `make old`,
  `make oldinstall`). The cas of v0 and v0p is `make oldcas` in `src/cmd/cas` (built in `old/`). Built programs are not in git.
- The driver `cc.c` with `OLD_V1`, `OLD_V0`, `OLD_V0P` runs `/lib/vN/cparse`, `codgen`, `popt`. `sccv1` (`-DSCC -DOLD_V1`) runs `/lib/v1/scparse`,
  `scodgen`, `spopt`, built with the switches of v1. v0 and v0p run `/lib/old/cas`;
  v1 runs `/bin/cas`. cpp, gopt, ld, crt0.o and libc.a are the shipped ones.
- `make -C host oldroot` builds all of them and installs them into a tree of symbolic links to the WEGA tree
  (`host/tools/oldroot.sh`, default `tmp/oldroot`, bin and lib real directories, guest /tmp shared). Then
  `z8k-emu -r <oldroot> /bin/ccv0p -c -O foo.c`.
- The switches of codgen are set in `codgen/oldcc.h`, the version Makefile names only `OLD_V0` or `OLD_V0P`: the native
  cc takes about 160 characters of -D options.

## 2 Compiler versions

### Dating

Most programs carry the stamp of their start-up file, `@[$]crt0.s Rev : 3.x <date>`, made at the build
(`src/lib/libc/crt/mkcrt0.sh`, `crt0.list`); the libc members linked into a program date it too. The passes cparse,
codgen, popt and cas have no stamp; their newest source dates are cparse 10/06/83, codgen 08/24/83, popt 03/25/83,
cas 07/83. The date of a source does not date the compiler that built it.

`OLDCC_DATES.md` (generated by `host/recon/datemap.py`) lists the 373 programs of the tree: crt0 stamp, own SCCS ids,
libc marks, D12 and D1. Two marks can be read from a binary without its source. D12: the old cparse packs the string
literals, the shipped one pads every odd one to an even address. D1, read from the frames of the functions that save
register variables: "slots" (as many never used frame words as saved registers: v1), "tight" (no unused word: v0),
"loose" (shipped).

### shipped

Builds byte-identically: cc, scc, ar, tar, dump, dumpdir, restor, sync, getud, putud, format, verify, copydisk, pburn,
the doscopy programs, the standalone programs (`make -C host checkall`). All of them are linked with libc members of
09/12/83 or later.

### v1 (01/83 .. 07/83)

- Switches: `OLD_D1` and `OLD_D12` (cparse), `OLD_D3` (codgen), `OLD_D20` (popt).
- Byte-identical: `/bin/size`, `/usr/bin/strip`, `/bin/mv` (also cp, ln), `/bin/rm`.
- ld: 55 of 59 functions strictly exact, data equal, corpus 146 of 146; open: place_sec, chk_ranlib, load2td, load1.
- Own code equal, the libc part not linked yet: write (all 5 functions). rmdir: its main differs by D4 and D18.
- Test bench (System III sources of 26 programs from 01/83 .. 07/83): 89 of 121 functions equal, the shipped cc 27.
- stdio of the time: `char *_ptr` and the V7 forms of getc/putc (`--_cnt >= 0` first); the stdio.h of the WEGA tree has
  `unsigned char *_ptr` and the other order.

### v1q (before v1)

- v1 with `OLD_D14Q` (codgen); cparse and popt are those of v1. Driver `ccv1q`, runs `/lib/v1/cparse`, `/lib/v1q/codgen`, `/lib/v1/popt`.
- Byte-identical modules of libc-v3.a (the libc in size) from C: filbuf 0_1, rdwr 0_1, malloc 0_1, printf 0_1.

### The time line v1r, v1q, v1

One switch apart each. v1r: no temporary for a return, `?:` through a temporary. v1q: with that return temporary. v1: `?:` without a temporary (changed after 01/05/83, by 01/24/83). The place of v1q between them is a guess: only libc modules witness it, of unknown build time. Not checked: whether v1r needs the cparse of v1 (`OLD_D1`).

### v1r (01/83)

- v1q with `OLD_D1R` (no temporary for the value of a return). Driver `ccv1r`, its own codgen. Byte-identical: `/bin/write`, `/bin/rmdir`, with `libc-v10.a`.

### v0 (1982)

- Programs: those of 1982 (sources 07/82 .., crt0 3.1 up to 11/82). Marks: tight frames (no unused frame word, no return
  temporary, leaf functions without a frame) and packed strings.
- Switches: `OLD_D12`, `OLD_D4R`, `OLD_D6T`, `OLD_D6C`, `OLD_D6D`, `OLD_D22` (cparse); `OLD_D2R`, `OLD_D18`, `OLD_D1R`, `OLD_D2W`, `OLD_D10`,
  `OLD_D3P`, `OLD_D4O`, `OLD_D2C`, `OLD_D2F`, `OLD_D2L`, `OLD_D2N`, `OLD_D6T`, `OLD_D2T`, `OLD_D6R`, `OLD_D3K`, `OLD_D2V`, `OLD_D2M`, `OLD_D2MO`,
  `OLD_D2P`, `OLD_D2U`, `OLD_D2G`, `OLD_D5S`, `OLD_D22`, `OLD_D5A`, `OLD_D2W6` (codgen); none in popt. Not `OLD_D1`,
  not `OLD_D3`. cas: the old one (D17).
- Byte-identical modules of libc-v1.a from C: isatty 0_1, stty 0_1, ftell 0_1, readsym 0_1, system 0_1, swap 0_2, printf 0_3.
- Test bench (System III sources of 38 programs of 1982, `oldcc.sh bench`): 131 of 153 functions equal, 221 differing lines.
- Byte-identical: `/bin/dc`, `/usr/bin/ranlib`.
- Open forms of the bench: the first register of a statement r2 where ours takes r3 (the getc macro on a global stream);
  the switch dispatch `ld r2,TAB(r3)` against `add r4,r4; neg r4; ld r2,TAB(r4)`; leaf functions without a frame (the
  renaming of register variables into low registers is done by popt `procopt`, in the shipped compiler too).

### v0p (the compiler of the passes)

- v0 with the differences that only the passes show. It built cparse, scparse, codgen, scodgen, popt, spopt and cpp: all
  seven are byte-identical, all their functions strictly exact.
- Switches: those of v0 and `OLD_D3KC`, `OLD_D3J`, `OLD_D2PO`, `OLD_D2Q`, `OLD_D2X`, `OLD_D3AW`, `OLD_D12K`, `OLD_D5G`, `OLD_D5T`, `OLD_D2A`, `OLD_D2O`, `OLD_D2QO`, `OLD_D2MO`,
  `OLD_D2PT`, `OLD_D16A`, `OLD_D6S`, `OLD_D3L`, `OLD_D23` (codgen). popt needs no switch.
- The corpus of cparse and scparse holds only with the ccv0p build: the heap contents of the .S file follow the data layout of the pass.

### vk: the compiler of the kernel objects

The objects of `/wega` (`usr/sys/sys/LIB1`, `usr/sys/dev/LIB2`) were made by an older scc. `sccvk` (`-DSCC -DOLD_VK` in `src/cmd/cc`) runs `/lib/vk/scparse`
(built in `src/cmd/cparse/build/segvk`, `OLD_D25`), `/lib/vk/scodgen` (`src/cmd/codgen/build/segvk`, `OLD_VK` in `oldcc.h` = `OLD_D3` and `OLD_D24`) and the
`/lib/vk/spopt` (`src/cmd/popt/build/segvk`: the shipped spopt with `OLD_D29`). Source forms did not help (20 forms of the statements tried); sccv1 (v1 scparse and spopt) is further away. Witnesses (identical):
ureg, sys1, tt0 (D3), sig, sys2, sys3, debug (D24, D25), lock (D3), tty (D29). The `make install` of `src/uts` is identical in all 31 files, `wega` and `LIB2` included.

- Switches: `OLD_D3`, `OLD_D24` (codgen), `OLD_D25` (cparse), `OLD_D29` (popt); section 3.

### The old scc of cas

cas was built by an older scc; its parser and `assemble` without `-O`, the other modules with `-O`. The working compiler
`sccvc` is v0p compiled for segmented code (measured 2026-11-11: every switch of v0 and v0p that vc did not have is
neutral on cas when added, alone and all together), with these differences:

- codgen (`OLD_VC` in `oldcc.h` defines `OLD_V0P`): without `OLD_D3KC` (cas copyfile: a parameter wanted in its register is
  taken as it is, as in v0), with `OLD_D13` (bit 31 of addresses), `OLD_D6J` (the dense jump table, segmented), `OLD_D24`
  (the mask of a long cast to a pointer, as vk) and `OLD_D2S` (symtype, one witness);
- scparse (the segvc rule): the switches of v0p (`OLD_D12 OLD_D4R OLD_D6T OLD_D6C OLD_D22 OLD_D6D`) with `OLD_D13` and
  `OLD_D25`. `OLD_D12` gives the data layout of /bin/cas in the real build (strings at the end of a file's data, unpadded);
- spopt: the shipped one with `OLD_D13`, `OLD_D45`, `OLD_D20S` and `OLD_D49` (v0p has no switch in popt).

Which switch has which witness in cas: `OLDCC_SWITCHES_VC.md` (all blocks of v0p are measured there; a switch without a
witness in cas is in vc because it is in v0p). `sccvc` is the compiler of `src/cmd/cas/Makefile` (`old/cas` stays with scc;
sccvc passes `-DSCCVC` to cpp, for the one form of cas the shipped scc cannot compile: `TABADDR` in cas.h):
`src/cmd/cc/build/segvc`, `/lib/vc/scparse`, `/lib/vc/scodgen`, `/lib/vc/spopt`, `/lib/old/cas`; linked with
`src/lib/slibc-v11.a`. The model and the real build (`make` in `src/cmd/cas`, stripped) have the sizes of the original;
`/bin/cas` is not byte-identical yet. The state per function is in `compare/cas/FINDINGS.md`.

A switch on a constant (`switch (sizeof(char *)) { case 4: ...; case 2: ...; }`): sccvc, ccv0 and the shipped cc load the
value into r2 and keep only the matching case, without a dispatch (`ldk r2,#4; calr igetl`); the shipped scc keeps the jump
and both compares. Witnesses in /bin/cas: igetaddr, putrow (the only two `ldk r2,#4` without a use).

### The old libc members inside size, strip, ranlib, cas

The Jan 1983 libc linked into these binaries shows D14 and differs from the shipped members by its source and by the
compiler (D1, D8). Its members are kept as cas sources in `src/lib/oldlibc`.

## 3 The differences

Each class: the form in the code, the pass, the mechanism, the switch, the witnesses. D21 is not used.

### D1 Frame size and frame places

- v1 (`OLD_D1`, cparse, `oalloc`): every register variable gets a place in the frame too, at its declaration, like an
  automatic variable of its type; the shipped one only char and short register variables under -O. ld, strip `copy`, mv.
- v0 (`OLD_D1R`, codgen, `delay`): no temporary for the value of a return; with a delayed x++ the value stays in r2, which
  stays taken while the increment runs (`ld r2,_crslab; inc _crslab,#1`: cparse getlab).
- v0: no frame for leaf functions, no home slots for register parameters.
- Not reproduced: one unexplained frame word in main, endload, slookup, pslookup, index16 of ld (kept as `int spare`);
  cas `putins` 12 bytes against 14, libc nlist and length 2 bytes smaller, fseek 14 against 20.

### D2 Scratch registers

All in codgen.

Free registers and pairs:

- v0 `OLD_D2W` (rweight, rsbuild): r0 has the weight 3 instead of 8 and the free list starts with the pairs rr2 rr0 rr4 rr6
  (shipped rr2 rr4 rr6 rr0), so r0 and rr0 come early. Weight 0 or 1 makes codgen run endlessly.
- v0 `OLD_D2F` (getreg): a free word register is taken only when its weight is not above that of the first free pair, else
  the pair is split (clocal: the copy goes to r2, not to r6 beside the parameter in r7).
- v0 `OLD_D2L` (getreg): an idle scratch word that only holds a name counts as free when it weighs less than the register
  getreg would take; the name is lost then (newsect `n = ++nsect; cp = &buf[3]` loads into r2 again). The name lives on as
  long as nobody needs the register.
- v0 `OLD_D2G` (under OLD_D2L): an idle word of the same weight as that register wins (mkdope: r3 against the split rr0).
- v0 `OLD_D2T` (under OLD_D2L): the register of a TEMP (the value of a switch, held from its start to the compares behind
  the bodies) counts as free while idle, so the bodies take r2 again (setreg, prtree, opact).
- v0 `OLD_D2P`: OLD_D2L for pairs, an idle pair that holds a name counts as free when it weighs less than the first free
  pair, and only rr0 or rr2 (an idle rr4 stays when rr6 is free: cas opxor, opor, opand, opshl, opshr, opadd, opsub); two idle words of a pair are given back and merge; for a word an idle lighter pair is given back and split.
- v0p `OLD_D2PO`: an idle odd word whose even half is free is given back when a pair is wanted and the even half weighs less
  than the first free pair (refid, dclstruct).
- `OLD_D2PO` leaves a word that holds a parameter (in every version: the passes built by v0p do not change with the limit).
  vc has `OLD_D2PO` too. Witness in cas: stenter (`p2->s_12 = blklevel` behind `... = (char *)p2 - (char *)STAB`: r3 still holds
  the constant 0x30, r2 is free, the address takes rr2 and the value r0); witness of the limit: symtype of cas (r3 holds the
  parameter `n`, the address goes to rr0).
- v0 `OLD_D2W6`: when a pair is asked for and rr2 and rr0 are taken, rr6 comes before rr4 (refid, argalloc); only the pair
  request, not the free list.
- v0p `OLD_D2PT`: OLD_D2P also takes the idle registers of a TEMP (conval).

Where a value goes:

- v0 `OLD_D2R` (allocreg): a load through a pointer goes into the register of its address first (`ld r7,@r7`), word
  registers only. `OLD_D2V`: only when that register weighs no more than the one getreg would take (main `argv[i]`, argalloc).
  Segmented (vc): a byte or word through rr2 or rr4 (`rr2(#4)`, `@rr2`, `rr2(r1)`) that only this load uses goes into the even
  half, also when that half is wanted (`ldb rl2,rr2(#4)`; a return value), or into the odd half when that is wanted (an argument in r3); the pointer is loaded again when needed (cas putrow,
  jdeps, yyparse, asmins, mkstring, putstab*, osymout and others). Not through rr6 (a parameter there stays: evalint). An index in an odd word register (`tab(r3)`): the value goes into the even half of
  its pair when that is free (`ld r2,tab(r3)`; cas optim, defsym, asmins, jprnew).
- v0 `OLD_D2C` (match, allocreg): a name found in a scratch register by fixname is that register, the tree takes it over and
  the register forgets the name (gotscal); not for parameters, and such a copy holds no name.
- v0 `OLD_D2N` (allocreg): a name loaded into a word register is not remembered there; only the register of an assignment
  keeps the name (ilbrace reloads `_pstk`, gotscal uses r2 for two statements).
- v0 `OLD_D2M` (allocreg): a word multiplied through a pair uses the pair of its even register when the odd half is free
  (adddef `ld r3,r2; mult rr2,#%0006`). `OLD_D2MO`: for an odd left register the pair below it when the even half is
  free or idle (dclstruct, dc `mult rr2,%5F24`).
- v0 `OLD_D2U` (rallo): the right operand of a long multiplication wants no register (upoff).
- v0 `OLD_D6R` (gswitch): the count register of cpir is in neither half of rr0.
- v0p `OLD_D2A` (match): the value of a long assignment used in a comparison is copied into a new pair that keeps the name
  (nidcl, beginit, endinit); not when the value goes to a register wanted for it.
- v0p `OLD_D2Q` (allocreg): a long loaded through a pointer goes into the pair of its even address register when the odd half
  is free, also when that pair is the wanted one. `OLD_D2QO`: also when an odd word register is wanted for the value
  (getstr). `OLD_D2O`: a long loaded through an odd address register goes into the pair below it when the even half is
  free or idle; segmented (vc) also when an odd word register is wanted (cas iputloc), as `OLD_D2QO`. Segmented (vc): through base and index (`ldl rr2,rr4(r2)`) into the pair of an even index, also when another
  pair is wanted (a copy follows; cas seekout).
- v0p `OLD_D2X` (allocreg): a long result of a binary operator goes into the pair of its left operand first (defalign); not
  for shifts, whose count register would get the operand's pair.

Open: ld place_sec (`r8 = (secorg[j] - q->tsize) & 0xff00`: a new register for the `and`), chk_ranlib; register variables of
leaf functions in scratch registers (sld); rr0 where the shipped cc takes rr4 (cas).

- vc `OLD_D2S` (allo3.c): a word in r3 widened to long (SCONV) takes the pair rr2, the first pair of the order, with r3 in
  it (`ldk r2,#0`); a word in another register gets a new pair as before (locadv: r7 into rr2). cas symtype (`unsigned n;
  ip->s_2 = n;`). One witness.
- v1 `OLD_D3` (cbranch): at the join label of `&&` and `||` the shipped codgen gives the idle registers back, the old one keeps
  them with their contents. ld init_entry, dseek.
- v0 `OLD_D3P` (regforsym): a name that lives in a register is taken from it also when the node wants another register, also
  under a cast between int, unsigned and pointers (argdebug, rstruct). Segmented (vc): under a cast between pointers only;
  `(unsigned)w` of an int parameter loads it from its frame home again (cas iputw, sputw).
- v0 `OLD_D3K`: a parameter stays known in its register at a label a jump has already named and behind `&&`, `||` and the `?:` of
  codgen (there word registers only); at a label only a later jump names, or none, it is forgotten (twords), unless the
  function ends right behind that label. Such a register is not a scratch one for the tree (tshape, istnode): an operator
  copies it first (fixclass).
- v0 (not v0p, `OLD_D3KC` sets the v0p side): a parameter wanted in its own register (also as the address of a load into it) is taken as it is, no copy (`ld r7,4(r7)`,
  `isatty`: no `ld r2,r7`); otherwise it is copied first (`ld r2,r7; ld r13,2(r2)`); a name in a scratch register is taken only when no lighter one is free (`ld r2,r3; ld r13,2(r2)`, dc 3 places); `&&` and `||` keep long parameters too (fseek); an idle pair
  that holds a parameter is not taken for a new pair; a parameter whose address is taken is forgotten, so it gets its home (swap); a parameter a statement assigns to is forgotten at the start of the statement (scalint `p = removc(p,n)`); behind a conditional jump the idle registers go back, the known parameters stay.
- v0p `OLD_D3KC`, one witness: `regforsym` (`if (s == fpsym1 || s == fpsym2) return symreg(s, off, type);`): the original reloads the long parameter `off` from its frame home behind the `||` (`ldl rr4,0(r15)`), without the switch it is taken from rr2. 9 source forms tried (a cast, `+ 0L`, `?:`, `!(.. && ..)`, a `goto` label, `|`, ...): none reloads (`OLDCC_LOG.md` 2026-11-08).
- v0p `OLD_D3J`: at a label that jumps have named, only the parameters known at all those jumps stay known; when the record in
  front of the label is a jump (the record `]` does not count), the parameters known at the jumps come back (tfree1, rmconv); of
  those only a long parameter still gets its home in the frame (notoff). At a label no jump has named (a loop head) all jump
  records are forgotten. With two jumps (buildtree, an `&&`) the original reloads.
- v0p `OLD_D3AW` (argplace): the register of a parameter is forgotten only for an argument that is the parameter itself, uses it
  as an address or goes through +, -, unary -, * or a cast (scmd, readsyms, readtab), or a parameter added to an address constant
  (exname), and only when it lies in the register the argument is wanted in: putbyte `bcon(v)` reloads, popt setcon
  `natural(loc)` is `ld r7,r6`. Not in the condition of a `?:`; its arms do not take a parameter from the wanted register (regof).
- v0p `OLD_D3L`: a word cast of a global long is not taken from the register that holds the long (freeparm).

Popt, not a difference of the compiler: `rmove` replaces the load of the slot stored last, so `fprintf(..., l)` behind
`l = lab = getlab()` takes r2 (prtdcon); where comjump merged two arms first, rmove no longer knows the slot and the load stays.

Open: ld chk_ranlib (`q = p` loads p from the frame, `p + n` uses r7 right after: guess, a parameter of another type, see longswap in OLDCC_LOG.md), libc malloc (`mult rr2,r6`); cas: `ld S0,r7`
followed by `ld r7,S0`.

### D4 Spill of arguments

- v0 `OLD_D4R` (cparse, argalloc): the register parameters in front of the first other parameter and behind the last one get no
  home in the frame; those between other parameters keep theirs (block: the spill `ldm` is contiguous).
- v0 `OLD_D4O` (codgen, stmt): the parameter list is walked from its end, so the register parameters are copied in the order of
  their declaration (`ld r14,r7; ld r13,r6`).
- Open: the rule of the spill itself (libc swap: the home of `x`, whose address is taken, written as `0(r15)`, of `l` as `@r15`;
  sld: a long parameter cast to a pointer read from its spill slot).

### D5 Index into local arrays

All in codgen, fixfld, mapregs, rallo.

- Old scc: `a[3]` of a local array addressed directly (`ldb S5(r15),rl2`), the shipped scc computes the address. cas.
- v0 `OLD_D5S`: an element of a local array with a variable index is (index + offset) + fp, the frame pointer added last (`add
  r2,#%0006; add r2,r15; ld r2,@r2`); not for a constant index.
- v0 (with `OLD_D5S`, not v0p): an element of a member array is base + (index + offset) (`s->name[i]`: `ld r2,i; inc r2,#6; ld r3,s; add r3,r2`); of a global array of structures (index*size + member + index) + address (`tab[t].n[i]`). ranlib.
- v0 `OLD_D5A`: the address of such an element whose value goes to a given register gets no register preference (dclargs).
- v0p `OLD_D5G`: an element of a global array of arrays is `(index + index) + address`, the address added last (newsect). Segmented
  (vc): the address first, the index behind it (`_a(r3)`); a constant second index is folded into the address (`lctab[i][1]` as
  `_lctab+4(r3)`; cas ohdrinit, symadjust, also `buf[1]` of a local array as a frame operand: escape).
- v0p `OLD_D5T`: the STREF form of OLD_D5S: a member of an element of a local array of structures is `(index + offset + member) +
  fp`; as an address wanted in a given register it gets no preference (popt procopt).

### D6 switch

Up to 3 cases compared one after the other, the dispatch in front of the bodies; with 4 or more a `cpir` table, values sorted,
bodies in source order. The shipped compiler uses `cpir` from 1 or 3 cases on, values, then a jump table behind the bodies.

- v0 `OLD_D6C` (cparse genswitch): up to 3 cases compared, the table from 4 cases on.
- v0 `OLD_D6T` (cparse genswitch, codgen gswitch): the value list stands right in front of its target list, and the target is
  loaded from the pointer cpir leaves behind (`ld r2,%0024(r3)`). Our cparse passes the values to codgen in a record `V swlab dlab
  tlab values` in front of the `C` record; this intermediate form is a guess.
  Segmented (vc, cas: escape, osymout, genwop, yyparse): the same lists; the target from the offset cpir leaves behind, less that of the
  second value, rotated, as the index of the targets, into the pair of the value: `ld r2,#Lv+2; sub r7,r2; rl r7,#1; ldl rr2,Lt(r7);
  jp @rr2`; the count of cpir neither in that pair nor in rr0 (r4).
- vc `OLD_D6J` (codgen gswitch, segmented): a dense jump table loads the target into the pair of the value (`rl r2,#2; ldl rr2,Lt(r2);
  jp @rr2`), as the nonsegmented one into the value register; the shipped one takes another free pair (rr6). Not for a value in
  rr0. cas: iputexpr, main, defsym, p2tag, asmins, getop, error and others.
- v0, v0p `OLD_D6D` (cparse genswitch): the limit of the jump table is 3 values per case, `range <= 3*(n-1)` where `n` counts one more than the cases; the shipped one `range <= 3*n` (zzzcode, switch of
  `fldsz`; doprnt 0_5: 4 cases over a range of 14 by cpir).
- v0p `OLD_D6S` (codgen, match): the value of a switch assigned to its register when it is already there prints no `ld r2,r2`
  (falloc).

### D7 Loop layout

`while`/`for` loops and goto loops with the test at the head are rotated under `-O` (the entry jumps to the test at the bottom);
without `-O` the head stays on top. Open: sld 0x7C26 keeps its head on top.

### D8 Conversion and loads of bytes

Unsigned char argument: old `ldb rh7,#0`, shipped `subb rh7,rh7` (cas ifile); old libc length `ldb rl3,@r2` + `testb rl3` against
`testb @r2`; char loads as `ldb`/`subb` or `extsb; and #FF`.

### D9 Shift by 8 bits

`w >> 8` as a byte move (`ldb rl7,rh7`) instead of `sra r7,#8`.

### D10 Shift of a long by a constant

v0 `OLD_D10` (codgen, match): `ld r2,#24; sdal rr4,r2`, shipped `slal rr4,#24`. The table entry 024 (the immediate shift) is not used
for a long, so the entries 025 .. 030 load the count into a register. Segmented (vc): a shift by one stays immediate (`sral rr4,#1`; cas asmrel), `<< 16`
goes through a register (symreloc).

### D11 Tail merging

Not reproduced in v1: ld load1 (the store behind a dead `ldl rr4,rr2` shared with the end of the loop); the cas scanner
(`call xtol; jp` shared by the number cases).

### D12 String literals and data layout

- v1, v0 `OLD_D12` (cparse, putstrs): the initialised data and the switch tables in source order, all string literals of a file
  behind them as one pool, aligned only at its start and end, equal strings not merged. The shipped one writes the strings of a
  function in front of it, each padded to an even address.
- v0p `OLD_D12K` (codgen, rddata, eread): a double constant goes into the data at its statement, not with the .D data at the head of
  the function (buildtree). One witness.

### D13 Pointer constants (old scc)

The assembler of the old scc keeps bit 31 of a segmented address constant (`ldl rr2,#%87000030`) and of every address of an `.addr` (pointer tables, jump tables: `%8400xxxx`, `%8500xxxx`); the shipped one clears both, and both keep it clear in `.long`. vc `OLD_D13`: cas `assemble.c` (a long immediate goes through `genlop` with the flag of an address), `parser.y` and `p2loop.c` (pass 1 marks an `.addr` list by the tags 0xE0 and 0xE1, pass 2 calls `genlop` with the flag between them), and spopt (`popt/z21.c`: a jump table entry is printed as `.addr`, the shipped one prints `.long`; `/lib/vc/spopt`). The cut members of `slibc-v11` (doprnt, cnvt, endopen) have their jump tables as `.long` and bit 31 clear, as in /bin/cas. `/lib/old/cas` (`src/cmd/cas/old`, with `OLD_CAS`; `OLD_D13` acts only in segmented code, so v0 and v0p are not touched), built by scc. scparse of vc with `OLD_D13` (local1.c, trees1.c): the cast of a constant to a pointer masks with `0xff00ffff`, bit 31 stays; scodgen of vc with `OLD_D13` (optim3.c): in `int + constant address` the address goes to the left (`ldl rr2,#%87000030; add r3,i`), where the shipped codgen makes the int register the target and stops with "register jam" (cas stabp, itabp, stalloc, italloc, namalloc, jsymadj, symadjust: `(char *)STAB + i`). Witnesses: cas `ssymtab` (immediates), the pointer and jump tables in the data of cas.

### D14 Varargs prologue and post-increment (old libc members)

`OLD_D14Q` (v1q; codgen store, the QUEST of order, freeparm, delay): the value of a `?:` of an integer type always goes through a temporary of the parameter area, at the start of the frame (`@r15`, the
autos behind it; `ld @r15,#1; jr; ld @r15,#%0200; ...; ld r5,@r15`). Each arm is assigned to it, the delayed `x++` of the arm follows that store (`ld @r15,r3; inc @r13,#1`, not in front of the arm). The temporaries of one function are not
used again: the offset goes up over the statements and calls (endopen: `@r15`, 2, 4). An `&&` on the left of a `||` also goes into such a temporary (endopen, with `(char)` operands). Witnesses: filbuf, rdwr, malloc, printf of size.

The printf family of size, strip and cas spills the EPU registers inline (`.word %4FFC,%8303,off`) and stores r6..r2 besides the
`ldm`; ranlib's has the shipped form. In size `*fp->_ptr++` uses the byte before the `inc`. `_filbuf` of size and ranlib: the
conditional value goes through a stack temporary.

### D15 Block layout of if/else

The old compiler keeps the source order of then and else and places goto labels where they stand. Open block-order differences: sld,
ld load2td (popt moves the then block of `if (flag)` in front of the switches).

### D16 Frame operand in arithmetic

v0p `OLD_D16A` (codgen, match): `++n` of a frame slot whose value may go to a temporary (cookie with INTEMP: the left operand of `*`)
is `ld A1,n; inc A1,#1; ld n,A1`, not `inc n,#1` (genswitch `p[++n]`); with the value wanted in a register for an address or stored
it stays in memory. `--` of a frame slot stays in memory under a compare (popt codemove, cpp dodef). "Only `++`" and "not an operand
of a compare" fit all programs equally; a `++` of a frame slot under a compare or a `--` with this cookie outside one would separate
them. One witness (`genswitch` of cparse, `range = p[++n].sval-p[2].sval;`). No source form replaces the switch: 9 forms tried (`n = n+1`, `n += 1`, `n++` before or after, `(p+(++n))->sval`, ...) leave `inc n,#1` (`OLDCC_LOG.md` 2026-11-08).

### D17 Jump and call form: the old cas

`callr` and `jpr` are decided by cas. The old cas runs its jump optimization (`optim`) also during the first pass, and a forward jump
to a label not defined yet becomes long there. Built with `-DOLD_CAS` (`host/cas/casold`, `src/cmd/cas/old`, `/lib/old/cas`).

- At an opening `{` with 176 undecided entries or more (`OLD_ENTBLK`; dc: the `{` of getwd has exactly 176, so its call of putwd stays long). The label of the
  function in front of the `{` is known then.
- When an entry would be made behind 255 entries (`OLD_ENTMAX`): functions too long for the first rule, yylex, rmove.
- A forward jump does not count a jpr that stands at its label (`>`, the shipped cas has `>=`): acon. One witness.

Why these limits is not known. Also dc of 07/82 follows the rule: from the System III source, split in front of add0 as WEGA has dc1.c
and dc2.c, all forms right. The manual (ZEUS Languages Programming Tools 3.2 and Band B, 3.4.5) names two
more conditions, `.=` and a difference of labels with a jump between them; no input has a case that depends on them, so they are not
built. The shipped cas and the ZEUS cas do not have them.

A `call` also comes from a callee in another module, because `calr` cannot leave a module. So sputc and aobeg of cparse are a module of
their own (sym2.c, the name is a guess), and hash, upoff, oalloc belong to sym1.c.

### D18 Frame operand with offset 0

v0 `OLD_D18` (codgen): the spills and saves are written `0(fp)`, never `@r15`. ld and codgen as originals built by other versions use `@r15`; v1
writes `%0000(r15)` for the home of a parameter where rmdir has `@r15`.

### D19 Order of evaluation of the operands of a binary operator

The old cc evaluates the left operand of `+`, `==`, `>` first when both are calls; the shipped cc the right one. Our sources of cparse
write these operands in the order that gives the bytes (`argregs`, `rmconv`, `clocal`).

### D20 Code motion of popt

- v0p: no old popt. The models built with the original /lib/popt as the pass of ccv0p are byte-identical to those with our popt.
- v1 `OLD_D20` (popt): a `jpr` to the label right behind it does not end a block to be moved, so short blocks in front of the function
  exit stay (ld ensure_buf, load1).
- vc `OLD_D20S` (popt): the same, but only for a straight block (no conditional jump in front of that `jpr`) whose label no other
  jump names. Witness: exprreloc of cas (the outer `default: return (0L);`, `subl rr2,rr2` in front of the exit, stays behind the
  dispatch codemove has moved; both dispatches jump to it). Without the limits exprval loses (its `return (v)`, refc 7, and the
  inner default are moved in the original); symtype and jdist need the limit to straight blocks. One witness, provisional.
- How popt places a block, and so what the source must look like: `codemove` moves a block behind a jump to the site of a jump to it. What
  decides is whether the node in front of a target is a jump: `if (c) goto L; L:` leaves `jpr L2; L:` and codemove takes the block,
  `if (!c) { L: ... }` does not. `xjump` in iterate looks one hop along a chain of jumps, and `comjump` runs before `rmove`: how many jumps
  stand behind a statement decides which copy of a tail stays (sucomp). `poptrace.sh` shows the passes for one function.

### D22 Doubles in rq4

v0 `OLD_D22` (cparse getpreg, argregs; codgen argscan, argplace, regargs, gencall, match): a double argument goes by its size, into rq4 (r4..r7)
when it is the first one; the next word argument then takes r3. A double parameter arrives in rq4 and is stored with the word parameters; a
double result comes back in rq4. The shipped compiler uses the EPU registers (f3 down). A floating compare with memory has no rounding `fld dbl`
of the left operand. The shipped atof of /lib/cparse returns in rq4 as well.

### D23 Zero addend

v0p `OLD_D23` (codgen, optim, mapregs): the optim of codgen does not take a zero addend away, so `(rv >> 8) - 1 + 1`, which cparse folds to
`x + 0` in its last step, stays `add r2,#0` (scodgen usable); a member at offset 0 and an index 0 add nothing at once. One witness (`usable`, `allo3.c`). No source form replaces the switch: every zero addend that cparse leaves, in whatever form written, is taken away by the optim of codgen (11 forms tried, `OLDCC_LOG.md` 2026-11-08); the zero in the original comes from the older codgen, which has no such rule.

### D24, D25 Mask of a segmented address

The kernel masks a user address with `(caddr_t)((long)x & 0x7F00FFFF)`. Original: `ldl rr4,rr2; and r4,#%7F00; ldl y,rr4` (a copy in a new pair, the mask on the copy); the shipped scparse and scodgen: `and r2,#%7F00; ldl y,rr2`.

- vk `OLD_D25` (cparse local1.c, SEG, PCONV): a cast of a long to a pointer stays a conversion (SCONV); the shipped scparse paints the type.
- vk `OLD_D24` (codgen optim3.c): `convelim` keeps a conversion between a pointer and a non-pointer of the same size. The SCONV of a long to a pointer then uses the template 040a (`ldl VA1,ALX; and A1,#%7f00`: the copy and the mask), and an `& 0x7f00ffff` under it is dropped.

The two work only together: each alone gives the code of the shipped compiler. Witnesses: `sig`, `sys2`, `sys3`, `debug` of the kernel. vc has both too (`OLD_D24` in `OLD_VC`, `OLD_D25` in the segvc rule of scparse): cas `yylex` (`(struct pst *)(q->s_2 & 0x7F00FFFFL)`: `ldl rr2,rr0; and r2,#%7F00`) and `igetaddr` (`return ((struct irow *)igetl());`: `ldl rr0,rr2; and r0,#%7F00; ldl rr2,rr0`). In cas a node holds its operands in pointer members of its union and a symbol its name in `s_name` (a union with the value `s_2`), so that only these two casts of a long to a pointer are left; with a cast at every node operand D25 would mask them all. No source form replaces them: 25 forms of the statement in `sig` (casts, `L` constants, order of the operands, `~`, `+ 0`, `| 0`, a long lvalue, parentheses) give the same code, temporaries are worse.

### D29 Layout of a table switch

vk `OLD_D29` (popt z21.c, `d29switch`, on the raw nodes of a function before the first pass of `iterate`). The raw code

    Lh: ld r,x; jp Ld; bodies; jp Lb; Ldf: default; jp Lb; Ld: cp r,#n; cjp ugt,Ldf; rl r,#2; ldl rr,t(r); jp @rr; Lb: jp Lo; Lk: block; jp Y

(a table switch with its default in front of the dispatch, left by a jump to the next statement) is laid out as

    Lt: rl r,#2; ldl rr,t(r); jp @rr; bodies; Lb: code at Lo; Lk: block; jp Y; Lh: ld r,x; cp r,#n; cjp ule,Lt; Ldf: default; jp Lb

Only the layout changes, what runs is the same. From this the shipped optimizer makes `TCXONC` in `ttiocom` of `tty.o`: the dispatch in two parts (`rl; ldl; jp @rr` in front of the bodies, `ld; cp; jr ule; jp default` behind `TCSBRK`) and the common tail behind the last body. The tail comes from `xjump`, which needs the label the bodies jump to right behind the last body and no `jp` right behind that label. One witness (`tty`, the source is the plain `switch` of System III); the evidence rule of two functions is not met. The raw code of the old compiler is not known, this is the layout that gives the bytes (owner decision 2026-11-09). `/lib/vk/spopt` is the shipped spopt with this switch; the other objects of vk stay identical.

### D45 A conditional jump over a jump, and codemove

vc `OLD_D45` (popt z21.c, iterate). At `cjp c,L1; jp L2; L1:` iterate turns the conditional jump (`cjp !c,L2`) before codemove
sees the `jp`. The spopt of vc does not turn it when codemove can take the block at L2 and that block is a head: it stands behind a
jump, is straight (no label, no conditional jump, at least one instruction), ends in a jump, and the target of that jump stands
behind another jump, and that jump does not go to the exit code (an L1xxxx label). codemove then puts the block behind the
conditional jump. Witness: stabout of cas (`if (*p == 0) break; p++;`
in the name loop, the block at the `break` is the head of `switch (tag)`: the second half of the dispatch and the check behind the
switch land behind the entry jump of the loop). One witness, the owner's exception; without the limits other functions of cas
change (`OLDCC_LOG.md`, 2026-11-10). The exit limit: jpr of cas (the type test of case 0x19, `cp 1; jr ne plain` in
the original, where plain ends in the jump to the exit); without it jpr has 24 lines instead of 10, nothing else changes
(2026-11-13).

### D49 Labels no jump names, and the loop inversion

vc `OLD_D49` (popt z21.c, refcount). refcount of the shipped popt deletes every label that no jump names, also one in a
run of labels. The spopt of vc keeps a label that no jump names when another label follows it (not when the exit code
follows, label L1xxxx). The loop inversion of codemove asks whether the label behind the jump is the one a conditional
jump in the loop names; such a kept label (the break label of a `switch` whose cases all end in a jump) stands in
between and the inversion is not made. Witness: yylex of cas (the done switch behind `tok = 3`: the `goto done` of the
default of `switch (c)` at the end of the `%` block is not taken as the back jump of a loop over done and the character
tests). One witness, provisional. Labels made unnamed by refcount itself (a jump moved to the last label of a run) go as
before: with them kept, genb, genw and 14 more lose their `for` inversion.

### Register allocation of the old scc

The register variables are assigned in declaration order from r13 downwards; an int or char takes one register, a pointer or long the highest
free aligned pair; a `register` parameter comes first. A leaf function puts them into scratch registers. (Nonsegmented cc: from r14 downwards.)
