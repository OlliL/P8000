# 130 Text and data files (etc, usr/lib, usr/other)

## Status

active (2026-11-17)

## Goal

Every file of the WEGA tree that is text or data (no program to compile) comes from `src/` and is installed by
`make install`, byte-identical.

## Done when

- COVERAGE shows no text or data file as `sys3` or `todo` (or each left one is listed here with the reason).
- checkall ALL OK.

## Read first

- `src/COVERAGE.md` (filter: kind text or data, status sys3 or todo).
- `host/tools/coverage.py` (how a source is found: install rules of the Makefiles).

## Known

- 2026-11-15: 293 files `sys3` (a System III source exists), 67 of them text; 191 `todo`.
- The System III tree (`tmp/sys3`) may be copied from (CLAUDE.md).

## Steps

1. The list: `src/TEXTFILES.md` (done 2026-11-17: 138 files, 33 scripts, 27 with a generator in System III).
2. Per directory: take the System III file or the WEGA file, compare, write the install rule; a WEGA-only file is taken as it
   is (a file with no other source is its own source).
3. checkall, COVERAGE new.

## Decisions

- Owner 2026-11-17: only kinds text and data (binaries and archives are not looked at); etc is done (all its text and data files are exact).
- The WEGA file is always what is copied; System III and Plexus are ideas only. Exception: where System III makes the file (macrunch/ntar
  for usr/lib/macros, maketerms for usr/lib/term, suftabmake, lint for llib-*.ln, spellin for the dictionary lists, mtab/mign for cref)
  the generator and all its inputs are taken 1:1 from System III; if the result is not byte-identical with the WEGA file, the WEGA file is
  copied. A file System III only copies, or has nothing for, is copied from WEGA.
- A script that lands in usr/bin gets a corpus (before it is taken over). Scripts elsewhere (usr/lib/acct): open.
- Nothing is taken over without the entry in `src/TEXTFILES.md` (generated by `host/tools/textfiles.py`) approved per directory.

## Not part of it

Programs and scripts that need a compiler or are tested by a corpus: 120, 160.
