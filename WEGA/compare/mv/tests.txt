# The cases of the corpus of mv, cp and ln: one program (src/cmd/mv.c) under three names, chosen by argv[0]
# (compare/mv/corpus.py, ALIASES); the format: host/recon/casefile.py. Where an expectation comes from: man =
# /usr/man/man1/mv.1, cp.1, ln.1, src = src/cmd/mv.c. Without a terminal mv does not ask before it replaces a target
# without write permission (src: isatty); the question: the user cases (terminal: console). mv dir1 dir2 links the
# directory (mv is set-uid root on WEGA): the emulator renames it (host/z8k-emu/README.md).

# ---- mv: the public interface (man page) ------------------------------------------------------------------------

# ---- the users (user:; the kernel's rules in the emulator) ------------------------------------------------------------
# mv is set-user-id root: it keeps root only to move a directory (src: mvdir: link of a directory, for the super-user
# only); for files it gives it up at once (setuid(getuid())). access() asks with the real user.

== user-mv-question
# src: a target the user may not write, on a terminal: "mv: b: 444 mode " and an answer; n keeps both files
