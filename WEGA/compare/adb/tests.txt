# The cases of the corpus of adb (compare/adb/corpus.py); the format: host/recon/casefile.py. The commands are the
# standard input (stdin: t.in); the files examined are programs of the WEGA tree with their symbols: /bin/bd
# (nonsegmented, E707), /bin/bcmp (nonsegmented, separate I and D, E711), /bin/fc (segmented, E607).
# Where an expectation comes from: src = src/cmd/adb (the file and function named).
