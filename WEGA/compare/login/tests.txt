# The cases of the corpus of login (compare/login/corpus.py); the format: host/recon/casefile.py (the default step is login).
# Where an expectation comes from: src = src/cmd/login.c (main), man = /usr/man/man1/login.1.
# t.in is the console input: the name, then the password (getpass reads /dev/tty, the console). At the end of the input
# getchar gives EOF and login exits 0. The output compared is the standard output, then "-- stderr" and the standard error
# (getpass writes Password: and a newline there). The prompt is the node name of uname (WEGA) and " login: ".

== unknown
# src: a name without an entry gets nouser (password "nope"), so any password is wrong
-- case
terminal: console
step: login
stdin: t.in
expect: exit 0
expect: output is 'WEGA login: Login incorrect\nWEGA login: Login incorrect\nWEGA login: -- stderr\nPassword:\nPassword:\n'
-- t.in
nobody
secret
