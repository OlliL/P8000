# The cases of the corpus of spell (compare/spell/corpus.py); the format: host/recon/casefile.py. H (the history file) is a file of the case in
# every step. Where an expectation comes from: src = src/cmd/spell.sh (a sh script: deroff -w takes the words, sort -u, the first
# /usr/lib/spell pass with the stop list (hstop), the second with the dictionary (hlista, with -b hlistb), the result sorted
# (sort -u +0f +0) and appended to the history file (tee -a $H), then who am i; -v lists the derivations too, -x the possible roots).

== misspelled
-- t.txt
This is a tset of teh spellng checker.
Color and colour are both fine.
-- case
step: /usr/bin/spell t.txt
expect: exit 0
expect: output contains 'spellng'
expect: output contains 'teh'
expect: output contains 'tset'
expect: output contains 'colour'
