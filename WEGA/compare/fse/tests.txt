# The cases of the corpus of fse (compare/fse/corpus.py); the format: host/recon/casefile.py. Every case runs with the
# minimal terminal (terminal: console; fse opens /dev/tty, puts it into RAW and writes the screen there) and TERM=P8,
# the terminal whose control sequences fsepar has put into the binary (the prefix of corpus.py). The keys come as the
# operator types them (\xNN: ^A = \x01 ... ^Z = \x1a, ESC \x1b, DEL \x7f, RETURN \r). Where an expectation comes from:
# man = /usr/man/man1/fse.1, src = src/cmd/fse. At the end of the typed keys stdin ends: a read of 0 bytes is the key
# F10 (src fsetty.c getkey: 0x00 0x00), save and quit; a case that must not save ends with ^UQ or ^UE. fse waits for
# ever at "Press <ET> to continue" and at "Save before quit ?" when stdin has ended (KNOWLEDGE.md, quirks): the cases
# answer there.

# ---- leaving the editor (man: ^UD ^UQ ^UE, the backup) -------------------------------------------------------------

== save-quit
line one
line two
-- case
step: fse -c t.in
operator: type 'abc\x15d'
# man ^UD: save and quit; the old state stays as t.in~ (backup, default)
expect: exit 0
expect: file t.in contains 'abcline one\nline two\n'
expect: file t.in~ contains 'line one\nline two\n'
expect: output contains 'Saving File:'
