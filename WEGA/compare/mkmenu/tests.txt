# The cases of the corpus of mkmenu (compare/mkmenu/corpus.py); the format: host/recon/casefile.py. The case directory is the guest's /tmp/CASE
# (pwd). HOME is /. Where an expectation comes from: src = src/cmd/mkmenu.sh (a csh script; gets reads one line of the standard input): with the
# name as argument "Menu is NAME" is printed and it is not asked for it; the four header lines and then the entries (0 next menu, 1 sh command,
# 2 csh command, 3 exit entry; another key: "Are you done?" y ends, else the entry number goes on) are written as lines to the file; at most
# 16 entries; the file gets mode 644.

== menu-by-name
-- in
Acme
Sys
Div
Title
1
ls
List files
2
date
Show date
q
y
-- case
step: /usr/bin/mkmenu mymenu
stdin: in
host: cat mymenu; stat -c %a mymenu
expect: exit 0
expect: output contains 'Menu is mymenu'
expect: output contains 'ls:1:List files'
expect: output contains 'date:2:Show date'
