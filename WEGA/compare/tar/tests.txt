# The cases of the corpus of tar (compare/tar/corpus.py); the format: host/recon/casefile.py. Every case starts with
# all its files at the time 1988-03-04 05:06:07 UTC (the archive holds the time of change). The case directory is the
# guest's /tmp/NAME (corpus.py, IN_TMP): tar finds it by /bin/pwd. Where an expectation comes from: man =
# /usr/man/man1/tar.1, src = src/cmd/tar.c. The devices: the cases disks-* (the floppy model of the emulator).

# ---- the public interface (man page) ----------------------------------------------------------------------------

== c-files
# man: c writes a new archive, f the archive file (made when it does not exist), t lists the names

-- f2
two

# ---- the signals (src: main, onintr, onhup, onquit, putfile) ----------------------------------------------------------
# For c, r, u tar catches INT, HUP and QUIT (unless ignored): the handler ignores the signal from then on and counts it
# (term); the loop over the names stops after the current one, the archive is ended as always (putempty), the exit
# status is 0. TERM is not caught (src: commented out, "WOFUER ???"). `p` is a FIFO between two files: tar waits in its
# open until the signal comes.

== signal-int
# src: INT while p is opened: p cannot be opened, f2 is not written; the archive holds f1 and its end
-- f1
one
-- f2
two
-- case
host: mkfifo p
step: tar cvf a.tar f1 p f2
signal: INT after 2
step: tar tf a.tar
expect: output contains 'step 2 tar: exit=0'
expect: output contains 'tar: p: cannot open file'
expect: output is 'f1\n-- stderr\ntar: blocksize = 4\n'

== signal-hup-quit

# ---- the users (src: putfile, gethead, doxtract; the kernel's rules: z8k-emu, user:) --------------------------------
# A case with `user: UID GID` runs as that user of WEGA (0 is root); its files belong to it. ls -n is not in WEGA's ls:
# the owners are shown by tar tv (uid/gid) and ls -l (the name from /etc/passwd, or the number).

== user-ids
# src (putfile): the archive holds the owner of every file; tv prints uid/gid
-- f1
one
-- case

step: tar cf a.tar f1
step: tar tvf a.tar
expect: output contains '100/10'

== user-root-extract

== user-extract-gives-away
# src (doxtract): a user who is not root: tar makes the file (its owner), then chown to the owner of the archive; the
# owner of a file may give it away (sys4.c chown, fio.c owner): f1 belongs to 100 afterwards. X: tar takes the ids of
# its user instead (gethead: getuid, getgid). The time of f1 is not set back after the chown (utime: not the owner any
# more): ls shows only mode and owner (the time is that of the run)
-- f1
one
-- case
user: 200 20
step: chown 100 f1
step: tar cf a.tar f1
step: rm f1
step: tar xf a.tar
step: sh -c "ls -l f1 > l"
host: cut -c1-30 l && rm l
step: rm f1
step: tar Xf a.tar
step: ls -l f1
expect: output contains ' 100 '
expect: output contains ' 200 '

# ---- the disks (src: inBL, diskend, readarchiv; the driver: ioctl SHOWFD, src/uts/dev/fd.c fdblocks) ----------------
# On a floppy device tar asks the driver for the size of the disk (SHOWFD: 360 blocks for format 9, 48ss9) and spreads
# the archive over several disks: at the end of one it waits 2 seconds (reading away what was typed), prints "insert
# next disk : ", waits for a newline and opens the device again. The operator (operator:) puts the next disk in and
# types the newline.

== disks-write-read
# src: c of 500 blocks of data onto disks of 360: two disks; the blocks used are counted at the end; t and x read them
# back with the same change of disks
-- case
user: 100 10
device: drive1 d1
host: python3 -c "open('big','wb').write(bytes(i % 251 for i in range(250000)))" && : > d1 && : > d2 && touch -d '1988-03-04 05:06:07 UTC' big
step: tar cvf /dev/rfd148ss9 big
operator: at 'insert next disk : ' insert drive1 d2 type '\n'
host: wc -c < d1; wc -c < d2; mv big big.orig
step: tar tvf /dev/rfd148ss9
operator: insert drive1 d1
operator: at 'insert next disk : ' insert drive1 d2 type '\n'
step: tar xf /dev/rfd148ss9
operator: insert drive1 d1
operator: at 'insert next disk : ' insert drive1 d2 type '\n'
host: cmp big big.orig && echo same
expect: output contains 'insert next disk : '
expect: output contains 'allocated space on  2 disks'
expect: output contains 'same'
